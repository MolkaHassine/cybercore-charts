# Cybercore Charts - Analyse de Données & Détection d'Anomalies

Traitement et analyse de logs réseau/applicatifs avec Python/R. Détection de comportements anormaux et visualisation.

## Objectifs
- Collecte et prétraitement de logs (réseau/applicatifs)
- Analyse exploratoire des données
- Détection d'anomalies (statistiques, règles, approches basiques)
- Visualisation interactive/graphique
- Mise en évidence d'indicateurs de compromission

## Technologies
- Python (pandas, numpy, matplotlib, scikit-learn)
- R (tidyverse, ggplot2)
- SQL
- Jupyter Notebook

## Structure
```
cybercore-charts/
├── data/        # Jeux de données (non versionnés si sensibles)
├── notebooks/   # Analyses et expérimentations
├── scripts/     # Scripts d'analyse et détection
├── reports/     # Rapports et graphiques
└── README.md
```

## Démarrage
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install pandas numpy matplotlib scikit-learn jupyter
jupyter notebook
```
